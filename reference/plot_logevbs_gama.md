# Plot log-EVBS Densities for Varying gamma

Reproduces Figure 2(b) of the paper: log-EVBS densities for \\\gamma \in
\\-1.05, -0.5, 0.5, 1.05\\\\, \\\alpha = 1\\, \\\eta = 0\\. Uses ggplot2
with the Dark2 colour palette.

## Usage

``` r
plot_logevbs_gama()
```

## Value

A `ggplot` object.

## See also

[`plot_logevbs_alpha`](https://raydonal.github.io/evbsreg/reference/plot_logevbs_alpha.md).

## Examples

``` r
print(plot_logevbs_gama())

```
