# Plot log-EVBS Densities for Varying alpha

Reproduces Figure 2(a) of the paper: log-EVBS densities for \\\alpha \in
\\0.25, 0.5, 2, 4\\\\, \\\eta = 0\\, \\\gamma = 0\\. Uses ggplot2 with
the Dark2 colour palette.

## Usage

``` r
plot_logevbs_alpha()
```

## Value

A `ggplot` object.

## See also

[`plot_logevbs_gama`](https://raydonal.github.io/evbsreg/reference/plot_logevbs_gama.md).

## Examples

``` r
print(plot_logevbs_alpha())

```
