# Plot EVBS Densities for Varying alpha

Reproduces Figure 1(a) of the paper: EVBS densities for \\\alpha \in
\\0.25, 0.5, 0.75, 1\\\\, \\\beta = 1\\, \\\gamma = 0.5\\. Uses ggplot2
with the Dark2 colour palette.

## Usage

``` r
plot_evbs_alpha()
```

## Value

A `ggplot` object.

## See also

[`plot_evbs_gama`](https://raydonal.github.io/evbsreg/reference/plot_evbs_gama.md),
[`generate_evbs_data`](https://raydonal.github.io/evbsreg/reference/generate_evbs_data.md).

## Examples

``` r
print(plot_evbs_alpha())

```
