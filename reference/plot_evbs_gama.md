# Plot EVBS Densities for Varying gamma

Reproduces Figure 1(b) of the paper: EVBS densities for \\\gamma \in
\\-1.25, -0.75, 0.75, 1.25\\\\, \\\alpha = 0.5\\, \\\beta = 1.5\\. Uses
ggplot2 with the Dark2 colour palette.

## Usage

``` r
plot_evbs_gama()
```

## Value

A `ggplot` object.

## See also

[`plot_evbs_alpha`](https://raydonal.github.io/evbsreg/reference/plot_evbs_alpha.md).

## Examples

``` r
print(plot_evbs_gama())

```
