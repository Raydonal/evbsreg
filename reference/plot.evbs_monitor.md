# Plot an endpoint-identifiability control chart

Plot an endpoint-identifiability control chart

## Usage

``` r
# S3 method for class 'evbs_monitor'
plot(x, ...)
```

## Arguments

- x:

  An object returned by
  [`evbs_monitor`](https://raydonal.github.io/evbsreg/reference/evbs_monitor.md).

- ...:

  Further arguments passed to `plot`.

## Value

Called for its side effect; invisibly returns `x`.
